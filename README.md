# 🌟 موقع DR & COACH | دكتور آند كوتش للتغذية الرياضية والتدريب

مرحباً بك! تم بناء هذا الموقع الإلكتروني الاحترافي لصفحتكم **DR & COACH** بالاعتماد على الشعار الرسمي الخاص بكم، ويجمع بين الهوية الرياضية والطبية في تصميم عربي عصري متجاوب بالكامل.

---

## 📁 محتويات المشروع ومكانه على جهازك
الموقع متواجد بالكامل في المجلد:
`C:\Users\PC-3\.gemini\antigravity\scratch\dr-coach-website\`

- 📄 **`index.html`**: ملف الصفحة الرئيسية للموقع (يمكنك فتحه مباشرة في أي متصفح مثل Chrome أو Edge بالضغط عليه مرتين).
- ⚙️ **`config.js`**: **(الملف الأهم)** ملف التحكم الشامل الذي يمكنك من خلاله تعديل كل شيء في الموقع بدون الحاجة لأي خبرة برمجية!
- 🎨 **`style.css`**: ملف التصميم والألوان المستوحاة من لوجو صفحتكم (الكحلي الداكن والأخضر الرياضي).
- ⚡ **`app.js`**: المحرك البرمجي الذي يربط الإعدادات، ويشغل شات الذكاء الاصطناعي مع Google، وحاسبة السعرات، ونوافذ الدفع والواتساب.
- 🖼️ **`assets/logo.png`**: صورة الشعار الخاصة بكم التي تم رفعها واستخدامها في الموقع.

## 🛠️ كيف تعدل على كل شيء من ملف `config.js`؟
افتح ملف **`config.js`** بواسطة أي محرر نصوص (مثل Notepad أو VS Code أو المفكرة):

### 1. تعديل رقم الواتساب والرسالة الترحيبية:
ابحث في الملف عن قسم `whatsapp`:
```javascript
whatsapp: {
  // اكتب رقمك بكود الدولة وبدون علامة + أو مسافات (مثال لمصر: 201012345678)
  phoneNumber: "201000000000",
  
  // الرسالة التلقائية عند الضغط على زر الواتساب
  defaultMessage: "مرحباً دكتور & كوتش، أود الاستفسار عن باقات التدريب والتغذية",
  showFloatingButton: true
}
```

### 2. إضافة وتعديل روابط صفحات السوشيال ميديا:
ابحث في الملف عن قسم `socialMedia` وضع روابط صفحاتكم الحقيقية:
```javascript
socialMedia: [
  {
    name: "Facebook",
    title: "صفحتنا على فيسبوك",
    url: "https://facebook.com/رابط-صفحتكم",
    iconClass: "fab fa-facebook-f",
    color: "#1877F2"
  },
  {
    name: "Instagram",
    title: "حسابنا على إنستغرام",
    url: "https://instagram.com/حسابكم",
    iconClass: "fab fa-instagram",
    color: "#E4405F"
  },
  // يمكنك إضافة صفحات أخرى مثل تيك توك وتليجرام ويوتيوب...
]
```

### 3. تفعيل الربط المباشر مع ذكاء جوجل الاصطناعي (Google Gemini AI):
ابحث في الملف عن قسم `geminiAI`:
1. ادخل على الرابط المجاني من جوجل: [Google AI Studio](https://aistudio.google.com/app/apikey)
2. اضغط على **Create API Key** وانسخ المفتاح.
3. الصق المفتاح داخل علامات التنصيص:
```javascript
geminiAI: {
  apiKey: "ضع_المفتاح_هنا_مثلا_AIzaSy...",
  model: "gemini-1.5-flash",
  systemInstruction: "أنت المساعد الذكي المعتمد لمنصة DR & COACH..."
}
```
> **ملاحظة ذكية:** حتى وإن لم تضع المفتاح الآن، سيعمل شات الذكاء الاصطناعي تلقائياً بنظام الردود الرياضية والتغذوية الذكية المدمجة!

### 4. إضافة وتعديل وسائل الدفع (إنستاباي، فودافون كاش، بنوك، فيزا، باي بال):
ابحث في الملف عن قسم `paymentMethods`، وعدل أرقام المحافظ والحسابات:
```javascript
paymentMethods: [
  {
    id: "instapay",
    name: "إنستاباي (InstaPay)",
    badge: "الخيار الأسرع بمصر",
    accountNumber: "اسم-حسابكم@instapay",
    instructions: "قم بالتحويل عبر إنستاباي ثم أرسل الإشعار عبر الواتساب..."
  },
  {
    id: "vodafone_cash",
    name: "فودافون كاش ومحافظ الهاتف",
    badge: "كاش / اتصالات / أورانج / وي",
    accountNumber: "010xxxxxxxx",
    instructions: "يرجى تحويل قيمة الباقة إلى الرقم أعلاه..."
  }
  // يمكنك إضافة أو تعديل أي وسيلة دفع أخرى
]
```

### 5. تعديل وإضافة البرامج الرياضية والتغذوية:
ابحث عن `sportsPrograms` (للتمارين والجيم) و `nutritionPrograms` (للأنظمة الغذائية) و `vipProgram` (للباقة الشاملة):
يمكنك تغيير:
- `title`: اسم البرنامج (مثلاً: برنامج الضخامة، برنامج التنشيف، باقة علاج السمنة ومقاومة الأنسولين).
- `price`: السعر الحالي.
- `originalPrice`: السعر قبل الخصم.
- `duration`: مدة الاشتراك (مثلاً: شهرين، 3 شهور).
- `features`: قائمة المميزات التي يحصل عليها المشترك.
